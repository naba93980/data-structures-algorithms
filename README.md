# Data Structures and Algorithms

A collection of code and practice exercises for learning Data Structures and Algorithms (DSA).

## About

This repository contains programs written while learning DSA, it serves as a personal collection of implementations, experiments, and practice exercises focused on understanding how data is organized, processed, and manipulated through different algorithms.

The code is organized by topic, making it easier to explore individual concepts and revisit implementations when needed.

## Topics

The repository is organized into language/topic-based folders, with source files and subfolders containing the corresponding implementations and exercises.


## Getting Started

### Prerequisites

- A compatible compiler or interpreter for the language used by the individual program.
- A code editor or IDE of your choice.

### Clone the Repository

```bash
git clone https://github.com/naba93980/data-structures-algorithms.git
cd data-structures-algorithms
```

### Explore and Run

1. Browse the folders to find a topic or implementation.
2. Open the relevant source file.
3. Compile or execute it using the appropriate tools for its programming language.

Individual programs may have their own compilation requirements or input expectations.

This repository preserves my early exploration of Data Structures and Algorithms and provides a reference for revisiting the concepts and implementations I worked on while learning programming.
